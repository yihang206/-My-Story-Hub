## 真实数据库测试方法

`tests/backend-rls.sql` 在单个事务内创建合成账号和作品结构，设置实际请求主体并切换为 anon / authenticated 后执行查询、越权写入和 RPC 断言。测试包含有授权读者、无授权读者、停用读者与管理员；检查未发布小节和草稿不对读者暴露，读者不能自升为管理员，其他人的记录与笔记不可读取，作者只能读取主动分享的笔记，发布保留旧正式版本，阅读秒数按增量正确累计。新增上传策略和显示名称函数也在相同方法下验证。末尾 ROLLBACK 并再次核对真实数据数量。

## 已知实现限制

- 发布父级状态为多个请求，非单个事务；部分失败显示明确错误、保留草稿，重试前核对小节以避免重复相同修订。
- 活动阅读时间为近似估算。模糊网络失败暂停自动重发秒数，避免重复累计；强行关闭页面可能丢失最后未同步的一段时间。
- 同一页面的草稿保存已处理竞态；多设备同时编辑同一小节仍采用最后保存者版本。
- 本轮使用 Chromium，未单独运行 Safari/WebKit；iPad 检查为相应视口与触摸布局的浏览器模拟。

以上限制没有通过修改现有生产函数、关闭 RLS 或扩大读者权限来绕过。

本轮追加读者视角预览验收：无需新建用户即可切换界面，已发布内容筛选、管理路由拒绝、背景常驻及退出还原通过；在阅读、笔记和设置页面操作后，测试确认没有任何写入请求。该模式仅预览界面，不模拟特定好友的 RLS 身份。
