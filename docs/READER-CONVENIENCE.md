# 继续阅读、登录偏好与修改初始密码

本次沿用现有账号、表结构和 RLS，没有数据库迁移或访问权限变更。

## 继续阅读

首页从当前用户的阅读记录中显示最近可访问且已发布的章节。点击“继续阅读”回到保存的位置；最近章节已完成且存在下一篇正式章节时，入口转向下一章。失去授权或已撤回的内容不会通过旧记录展示。新读者没有记录时不显示虚构入口。

阅读时停止滚动约 1.2 秒后同步，切换页面、退出和页面转入后台也会尝试同步。复用原有阅读 RPC 写入进度及有效时长，再以本人条件更新 reading_progress.paragraph_index。两步串行；段落更新失败可在下一次同步重试，不会重复添加上一段阅读时长。恢复优先使用小节和段落索引，旧记录没有有效段落索引时仍可按原百分比恢复。浏览器强制终止或断网时，尚未成功上报的位置仍可能丢失。

## 登录偏好

- “记住账号”只保存当前浏览器的邮箱，不保存密码。
- “自动登录”使用 Supabase 的登录会话与刷新机制；默认不勾选。勾选后在当前浏览器保留会话，不勾选时会话仅保留在当前标签页。
- 主动退出清除当前浏览器的登录凭据；邮箱和选项按用户偏好保留。退出采用 local 范围，不主动退出其他设备。
- 已登录用户也可通过个人设置修改登录偏好。关闭自动登录会将当前会话从持久存储转到当前标签页。
- 升级前已有的登录会话会迁入当前标签页，让升级过程不中断本页登录，不会未经用户选择勾选自动登录。
- 自动登录仍受后端会话有效性、账号启停状态及浏览器存储可用性影响。恢复后继续向后端验证有效档案，才加载私人素材与页面。

## 修改初始密码

读者在个人设置填写当前密码、新密码和确认密码。先重新验证当前密码，再调用 Auth 的密码更新。新密码至少 8 位，两次输入一致且与旧密码不同。成功后退出当前会话并明确提示使用新密码重新登录。密码不会写入 localStorage、sessionStorage、项目文件或日志。

## 验证

12 项单元测试覆盖原有核心逻辑和记忆/自动登录存储逻辑；浏览器用例包括新标签页、显式退出、改密成功与错误密码、续读段落、已完成章节、失去授权记录和四种屏幕排版。浏览器使用合成账号和请求夹具，不更改真实账号密码。真实数据库以可回滚事务验证本人段落检查点更新和既有五种身份权限边界。
